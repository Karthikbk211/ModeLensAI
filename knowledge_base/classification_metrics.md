# Classification Metrics and Model Failure Analysis
Accuracy measures the fraction of all predictions that are correct. Precision measures how often predicted positive cases are actually positive. Recall measures how many actual positive cases the model identifies. F1-score balances precision and recall.
A model can have high accuracy while still performing poorly on a minority class, especially when the class distribution is imbalanced. Class-level precision and recall should therefore be inspected instead of relying on accuracy alone.
