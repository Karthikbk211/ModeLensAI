# Class Imbalance
Class imbalance occurs when some target classes contain substantially more observations than others. A classifier may achieve high overall accuracy by performing well on the majority class while missing minority-class examples.
Useful investigation areas include class distributions, per-class recall, confusion matrices, class weights, resampling methods such as oversampling or undersampling, and threshold selection where applicable. Imbalance is a possible contributing factor, not proof of the cause of an observed error pattern.
